# elaizaremo.com

Personal portfolio of Elaiza Remo, full-stack developer in Edmonton.

Built with React. Pushing to `master` builds the site and publishes it to GitHub Pages.

## Editing

- Text, links and projects: `src/elaiza/content.js`
- Page layout: `src/elaiza/Portfolio.js`
- Styles and the time-of-day sky themes: `src/elaiza/portfolio.css`
- Images: `public/assets/`

## Running locally

```
npm install
npm start
```

Add `?sky=morning`, `?sky=day`, `?sky=dusk` or `?sky=night` to the URL to preview each sky.
